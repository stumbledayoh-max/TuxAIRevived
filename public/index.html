⚙️ Configuração do servidor de geração (só para o dono do site)

Na Vercel fica só a interface — quem compila o APK é o backend (Render/Railway/VPS). Cole a URL dele aqui para testar neste navegador, ou configure de forma definitiva no arquivo vercel.json (recomendado, vale para todos os visitantes).

O APK gerado é assinado com chave de teste e instala em qualquer Android (ative “instalar de fontes desconhecidas” se pedir).
Para publicar na Play Store, assine depois com sua própria chave. Feito com WebView nativa — Android 7.0 ou superior.
